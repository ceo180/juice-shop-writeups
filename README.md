# OWASP Juice Shop - Team Exploitation Guide

This repository contains our team's documentation and step-by-step write-ups for all 107 OWASP Juice Shop challenges. This project demonstrates our methodology for identifying, exploiting, and remediating web application vulnerabilities across various security categories.

## Workflow

1. **Check Your Assignments:** Review your designated challenge list in the `assignments/` directory.
2. **Start a Task:** Pick a challenge from your list. 
3. **Draft the Write-up:** 
   - Copy `template.md` and rename it to `challenge-name.md` (e.g., `zero-stars.md`).
   - Move the file into the corresponding folder inside `categories/`.
   - Fill out the template thoroughly. Place any screenshots in `assets/images/` and link them using relative paths.
4. **Submit:** Commit your file and check the box on your assignment markdown file.

## Rules of Engagement
* Document exactly what payload or action triggered the flag.
* Do not rely solely on automated scanners; provide the manual reproduction steps.
* Ensure all code blocks and payloads are properly formatted.
